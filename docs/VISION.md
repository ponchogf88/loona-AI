# Visión LOONA

LOONA es el OS personal de Chuy. No un chat. No un clon de Zoey. Una cara que habla, un vacío con pocas estrellas, y tableros de la vida real.

## Norte

1. **Presente (escritorio).** HUD + voz + briefing de mañana + dashboards de vida.
2. **Corto plazo (esta quincena).** Los tableros dejan de ser maqueta: datos reales (salud, dinero, rutina, comida, calendarios, inbox).
3. **Cercano.** App iOS y Android con la misma cara y la misma voz.
4. **Red.** Varias LOONA (o productos-hijos) que se hablan entre ellas: un agente tipo Jarvis que coordina a otros Jarvis.

## Malla de agentes (no es “algún día”)

Cada producto LOONA es un nodo:

```
LOONA-core (voz + identidad)
  ├─ LOONA-salud
  ├─ LOONA-dinero
  ├─ LOONA-cuerpo
  ├─ LOONA-studio (Likinya / AMDA / consulting)
  └─ LOONA-inbox
```

Contrato entre nodos:

- Mismo `SOUL` raíz. Un owner. Un timezone MTY.
- Mensajes cortos con `intent`, `evidence`, `need_human`.
- Nadie publica, paga o borra fuera de sandbox sin NEED_HUMAN.
- Si un nodo no tiene dato, dice “no sé”, no inventa un saldo.

Eso es la comunicación Jarvis↔Jarvis. No un group chat de LLMs sueltos.

## Móvil

- Misma marca (luna hairline, void, estrellas sparse).
- Widget de mañana en la lock screen.
- Micrófono de captura (“desayuné…”, “pagué CFE…”).
- Push solo de lo que importa (corte de tarjeta, racha rota, mensaje de un humano).

## Lo que nunca es

- Un feed social más.
- Un ERP disfrazado.
- Zoey con otro color.
- Una agencia de animación. El explainer enseña **este** producto.
