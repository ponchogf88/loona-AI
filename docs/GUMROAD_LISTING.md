# Gumroad listing — LOONA

## Título

LOONA — tu OS personal local: World View, voz y noticias

## Subtítulo

No es un chatbot: es una cara de luz, una pantalla viva y un cerebro que corre en tu Mac.

## Incluye

- World View de partículas Three.js dentro de un escenario glass.
- Noticias con fotos y control TV on/off.
- Timeline día / semana / quincena / mes / año.
- Voz neural Dalia y chat con provider configurable.
- App 24/7, LaunchAgent e instalador de login.
- FastAPI local, configuración JSON Schema y guardrails.
- Telemetría opt-in para estudios de uso.
- Guía visual `docs/GUMROAD_LOONA.pdf` y `docs/HOW_IT_WAS_BUILT.md`.

## Lo que incluye el zip

`LOONA.app` · `hud/` · `runtime/` · `scripts/` · `config/` · `identity/` · `docs/` · `README.md` · `LICENSE` · `.gitignore` · `.env.example`

## No incluye

API keys de DeepSeek/Gemini ni credenciales de terceros. El comprador usa las suyas.

## Requisitos

Mac, Chrome, Python 3.11+. Intel con 16 GB+ o Apple Silicon.

US$29–49 setup · US$79 con 1 h de onboarding.
