# Dashboards de vida — corto plazo

Live shell: [http://127.0.0.1:8766/dash.html](http://127.0.0.1:8766/dash.html)  
Desde el HUD: botón **VIDA**.

Esto **no es visión**. Es el siguiente piso del producto. Las cifras que ves hoy son **placeholder**. No las cites como reales.

## Módulos

### 1. Salud en general
Sueño, recuperación, pasos, FC, HRV, peso, ánimo, hidratación, suplementos.  
Fuente: Apple Salud / CSV / voz.

### 2. Finanzas personales
Ingresos, gastos, suscripciones, compromisos, deudas, tarjetas, pagos, servicios.  
Fuente: Notion Finanzas o CSV. Un corte = una fecha. LOONA avisa; no paga.

### 3. Ejercicio
Rutina del briefing, registro, avances, metas, racha, motivación.  
Check del día = un tap o “ya hice core”.

### 4. Alimentación
Dieta del día, macros groseros, agua. Captura: “LOONA, comí …”.

### 5. Calendarios (cuatro, no uno)
- Actividades (vida)
- Publicaciones de redes (Likinya / LOONA)
- Trabajo (studio)
- Proyectos (AMDA, consulting, etc.)

Google Calendar MCP ya existe en el iMac. Corto plazo: `/api/calendar` deja de ser seed.

### 6. Centro de mensajes
WhatsApp, IG, FB Messenger, TikTok, Gmail, Telegram.  
Una bandeja. Columnas que el humano reordena.  
ToS: IG/FB/TT inbox = browser o API oficial. No scrapers sucios.
